Pepper V21 Drive Backup

Pepper V21 Drive Backup is a single-owner utility that preserves verified source snapshots and native test evidence from a private GitHub repository to the owner's Google Drive account.

What it does

After an explicitly authorized native Xcode test succeeds, a private GitHub Actions workflow validates the archive, source manifest, protected assets, and checksums. It then places the verified source ZIP and test evidence in a quarantined Google Drive folder.

It does not publish an iPhone application, deploy code, or modify the installed Pepper app.

Google Drive access

The owner authorizes Google Drive access through OAuth to permit uploading and verifying backups. The OAuth permission may grant broad Drive access; the backup workflow restricts its operations to the owner's Pepper project folder. Credentials are stored as GitHub Actions secrets, not on this website.

The service is for personal use, not public signup. It does not sell user data or use Drive content for advertising.
