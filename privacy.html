Privacy policy

Effective November 7, 2026. This policy applies only to the personal Pepper V21 Drive Backup integration, not to other Pepper services or applications.

Who uses this integration?

This is a single-owner software-development and backup utility. It has no public user registration and is not intended to collect information from other users.

What Google data is accessed?

The owner grants OAuth permission to access Google Drive. Depending on the scope shown during authorization, this permission may technically allow access to Drive files outside the backup folder. The backup workflow is configured to transfer, list, and verify files only within the owner's designated Pepper master backup folder.

How is data used?

Verified Pepper source ZIPs, checksums, manifests, and native XCTest logs are uploaded from private GitHub Actions runs to the owner's Google Drive. Files may be downloaded temporarily by the workflow for integrity checks. This is strictly for owner-controlled backup and software development.

Where are credentials stored?

Google OAuth tokens and client credentials are placed in the owner's private GitHub Actions Secrets and in the owner's local rclone configuration. They are not embedded in this public website or committed to the GitHub source repository. GitHub and Google process data as infrastructure providers for the backup operation.

Sharing, advertising, and sales

The backup utility does not sell Google user data, use it for advertising, or share it with independent data brokers. Google Drive files remain under the owner's Google account. The private GitHub Actions workflow and Google Drive services process only the files needed for backup.

Retention and deletion

Source archives are stored in private, owner-controlled Google Drive folders. Automated CI-generated snapshots are kept separately from protected accepted builds. A read-only retention audit identifies the latest verified review candidate and two predecessors and marks older CI snapshots for future review after at least 48 hours. The audit does not delete anything. Protected historical baselines are never targeted by this retention audit. The owner can manually remove Drive backups, revoke OAuth access, or change GitHub secrets.

Security

Transfers use authenticated HTTPS connections and archives are checked against hashes and source manifests. No online system can guarantee absolute security. Access to the private GitHub repository, Google account, and OAuth credentials must remain restricted to the owner.

Control and questions

The owner can revoke access at Google Account third-party connections. Questions about the OAuth application can be sent to the contact address provided on its Google OAuth consent screen.
